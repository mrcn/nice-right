3. Restore from `/tmp/` backup: merge `testing-hooks.json` back, verify `settings.local.json` still intact
4. Reconcile `CLAUDE.md`:
   - Keep verbatim: "Behavioral Rules (Always Enforced)", "File Organization", "Project Architecture" (DDD section), "Build & Test", "Security Rules"
   - Replace: title line, "Project Config" block (Topology/Max Agents/HNSW), "Swarm Orchestration" npx commands, "V3 CLI Commands" table, "Memory Commands Reference", "Quick Setup", "Support" links

5. Run `ruflo doctor --fix` — fix any issues it reports
6. Run `claude mcp list` — verify ruflo MCP server appears
7. Run `npm run build` — confirm nothing broken
8. Commit: `chore: init ruflo, reconcile project config`
